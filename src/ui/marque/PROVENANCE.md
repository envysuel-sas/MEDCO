# Marque — provenance

Fichiers produits par `node scripts/extraire-marque.mjs` depuis
`docs/maquette/export/Gemini_Generated_Image_s9dc0is9dc0is9dc.png`.

**Rien n'est redessiné.** Le script détoure le fond par diffusion depuis les
bords, puis recadre. Toute correction de la marque passe par le fichier
source, jamais par les fichiers produits.

| Fichier | Rôle | Dimensions |
|---|---|---|
| `logo.png` | verrouillage complet, mot-symbole compris | 1098×398 |
| `monogramme.png` | pictogramme seul, cadré carré, base des icônes | 427×427 |
